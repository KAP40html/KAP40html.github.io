# Portfolio Andy Morio - V1

Site statique 100 % HTML / CSS / JavaScript.

## Tester le site
Double-cliquer sur `index.html`.

## Fichiers
- `index.html` : contenu du site
- `style.css` : design
- `script.js` : menu mobile + animations
- `assets/CV_Andy_Morio_2026.pdf` : CV téléchargeable

## Publication
Le site ne nécessite ni base de données ni serveur applicatif.
Il pourra être publié gratuitement sur un hébergement de pages statiques.

- QR code sur le CV
